# ScrumCoin — Ideas & Issues

Welcome to the public idea and issue tracker for **ScrumCoin**.

## What is ScrumCoin Chat?

ScrumCoin Chat is a browser-based app that runs a virtual AI Scrum team on your machine — powered by local LLMs via Ollama. No backend. No API keys. No cloud.

Type a backlog item. The Scrum Master assembles 2–5 relevant specialists from a roster of 15 (Product Owner, Architect, Senior Dev, Security Engineer, UX, DevOps, QA, and more). Each agent streams their thinking live, token by token, into color-coded chat bubbles. You approve the team before dispatch, edit stories inline, and stop any agent mid-generation.

## How to contribute

### 💡 Submit an idea
Have a feature request or a suggestion? Open a [new issue](https://github.com/scrumcoin/ideas-and-issues/issues/new?labels=idea) with the `idea` label and describe:

- What the idea is
- Why it would be useful
- Any rough implementation thoughts

### 🐛 Report a bug
Found a bug? Open a [new issue](https://github.com/scrumcoin/ideas-and-issues/issues/new?labels=bug) with the `bug` label and include:

- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, browser, version)

### ❓ Ask a question
Use the `question` label for [general questions](https://github.com/scrumcoin/ideas-and-issues/issues/new?labels=question) about ScrumCoin.

## Labels

| Label       | Purpose                     |
|-------------|-----------------------------|
| `idea`      | Feature requests / ideas    |
| `bug`       | Bug reports                 |
| `question`  | Questions & discussion      |
| `enhancement` | Small improvements        |

## Community guidelines

- Be respectful and constructive
- Search existing issues before posting
- Keep one issue per idea/bug
